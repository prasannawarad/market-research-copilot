# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Brownfield restyle, not a greenfield build.** This is a live Flask + vanilla-JS/CSS app (`app/templates/index.html`) with no build step, no framework, no component library. Every value below either (a) preserves an existing production token/value verbatim (cited with a line reference), or (b) is a new value Claude's Discretion, per `01-CONTEXT.md`. Nothing in this contract requires renaming/removing any DOM ID, class, or `data-*` attribute — see `01-RESEARCH.md`'s "Verified Contract Inventory" for the full locked list, which this spec does not touch.

## Spacing Scale

Declared values (multiples of 4 only). Extends the template's default scale with a `--space-3: 12px` step to match this app's existing dense-table/compact-panel density (research Pattern 4).

| Token | CSS var | Value | Usage |
|-------|---------|-------|-------|
| xs | `--space-1` | 4px | Tag/pill internal padding, icon-scale gaps |
| sm | `--space-2` | 8px | Row/form-control gaps (`.row{gap:8px}`, preserved) |
| sm+ | `--space-3` | 12px | Table cell horizontal padding, compact card internal padding |
| md | `--space-4` | 16px | Card/panel internal padding, default element spacing |
| lg | `--space-6` | 24px | Panel-to-panel margin, section padding |
| xl | `--space-8` | 32px | Layout gaps, page top padding |
| 2xl | `--space-12` | 48px | Major section breaks (mast → strip → tabs rhythm) |
| 3xl | `--space-16` | 64px | Page-level bottom spacing (replaces the current non-token `padding:0 20px 80px` at `index.html:16` with a clean multiple-of-4 value — a CSS-property-only change, not an ID/class/contract change, so it is D-07-compliant) |

**Exceptions:** none required. All current interactive controls (buttons ≥9px vertical padding + border, tab pills ≥6px vertical padding) already exceed a comfortable click target once card padding is applied; no icon-only 44px touch-target case exists in this phase (no icon-only controls in the current UI).

### Radius & Elevation (card system, D-08)

Claude's Discretion values for the modern SaaS-dashboard card treatment (Linear/Vercel/Stripe reference, per `01-CONTEXT.md` §Specific Ideas). Replaces the current flat `border-radius:2px` on `.panel`/`.tab`/`button` (verified `index.html:32,35,44`).

| Token | Value | Usage |
|-------|-------|-------|
| `--radius-sm` | 4px | Buttons, inputs, tab pills, `.tag` pills |
| `--radius-md` | 8px | `.panel` cards, KPI stat tiles (`.strip > div`) — the primary "card" radius |
| `--radius-lg` | 14px | Reserved for future elevated surfaces (modals/callouts) — not used by any element this phase |
| `--shadow-sm` | `0 1px 2px rgba(19,26,36,.06)` | Resting elevation for `.panel` cards and KPI stat tiles |
| `--shadow-md` | `0 2px 8px rgba(19,26,36,.08)` | Elevated/active state — applied to `#detail-panel` when it is shown (not `.hide`), signaling "this card is in focus" |

`.panel` and `.strip > div` both get `border:1px solid var(--rule)` **and** `box-shadow:var(--shadow-sm)` (border is kept, not replaced, for definition at small sizes — shadow adds the "card lift" that makes this read as SaaS-dashboard rather than flat-bordered-table).

## Typography

Existing sizes in production range from 9px–22px across ~7 ad hoc values (verified `index.html:17,21,23,27-28,31,37,40,44,49-50,54,65-66,69`). Consolidated into a 4-role scale per D-05/D-06's sans/mono split — this is the mapping the restyle pass applies; it is a CSS-value-only consolidation, not a markup/ID change.

| Role | Size | Weight | Line Height | Applies to |
|------|------|--------|-------------|------------|
| Body | 15px | 400 (regular) | 1.5 | Table cell text, `.hit .txt`, `.note` body text, `body` default (already 15px at `index.html:17` — preserved) |
| Label | 10px | 600 (semibold) | 1.2 | `--mono`, uppercase, letter-spaced: `th`, `.tag`, `.strip .k`, `.hit .meta`, `.note .meta`, `.who` (consolidates the current 9–11px cluster) |
| Heading | 12px | 600 (semibold) | 1.2 | `--mono`, uppercase, letter-spaced: `h2` panel section titles, `.tab`/`.tab.on` nav buttons, `.wordmark`, `button` text (consolidates the current 11–13px cluster) |
| Display | 24px | 600 (semibold) | 1.2 | `--mono`, tabular-nums: `.strip .n` KPI stat-tile big numbers only (was 22px at `index.html:27` — bumped to 24 for scale cleanliness; zero functional risk, not an ID/class) |

Exactly 4 sizes, exactly 2 weights (400/600), per contract discipline. Input/textarea text stays sans at 14px/400 (existing, `index.html:40` — unchanged, it's form-control text, not one of the 4 declared roles, and template inputs aren't part of the type-scale hierarchy).

## Color

Existing token set (verified `index.html:8-14`) is preserved verbatim — no renames, since `.tag`, `.sym`, `.up`/`.down`/`.flat`, and every `td.num` reference these custom properties directly. Per the Open Question in `01-RESEARCH.md`: **`--accent:#1d6fe0` is kept as-is**, not shifted toward a more purple-leaning indigo — it is already a cool, trustworthy blue in live production use, already satisfies D-04's stated rationale ("trustworthy/analytical, doesn't collide with red/green"), and keeping it is zero-risk/zero-regression versus an unforced hue change.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#fbfbf9` (`--paper`) | Page background — the majority surface of every view |
| Secondary (30%) | `#ffffff` (`--surface`) | `.panel` cards, KPI stat tiles, inputs/textareas, table backgrounds; paired with `#e4e4dd` (`--rule`) for card/table borders |
| Accent (10%) | `#1d6fe0` (`--accent`, unchanged) | See explicit reserved-for list below — never applied as a general "all buttons/links are blue" rule |
| Destructive | `#b4362c` (`--down`, unchanged, dual-purpose per existing convention) | Remove/delete buttons (`.x`), `.err` error text — same token already used for down-trend price data per D-04 ("data semantics, not UI chrome" — this dual use predates this phase and is not being split into a second token) |

**Accent reserved for (explicit list — nothing else):**
1. Primary action buttons: `button` default (Add to watchlist, Search, Save note, Apply signals filter) — solid `--accent` background, white text (replaces the current `--ink`/black default button background at `index.html:44-46`)
2. `.sym:hover` — ticker symbol hover state (existing, `index.html:57`, unchanged)
3. `.hit a` — search-result headline links (existing, `index.html:67`, unchanged)
4. `.tag.agent` — agent-authorship pill text color (existing, `index.html:63`, unchanged)
5. Input/textarea `:focus` border + outline (new — standard focus-visible affordance, not previously styled)

**Explicitly NOT accent:** `.tab.on` (active tab pill) stays `--ink` background (existing, `index.html:34`, unchanged) — a neutral "selected" state, kept separate from "primary action" accent to hold the 10% discipline tight rather than letting accent cover both "selection" and "call to action" semantics. `button.ghost` and `button.x` keep their existing neutral/destructive treatments (`index.html:47-48`, unchanged) — only the bare `button` default switches to accent.
